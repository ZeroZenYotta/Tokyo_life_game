# 东京人生：心动与野心 — MVP 0.1

这是一个可运行的手机网页原型，用于验证微信小游戏的核心玩法。

## 运行方式
1. 解压 ZIP。
2. 在浏览器中打开 `index.html` 即可游玩。
3. 推荐用手机 Safari/Chrome 打开；当前存档保存在该浏览器的 localStorage 中。

## 当前实现
- 随机人生起点、家庭背景、性格、年龄、初始资金与属性
- 学识、技能、社交、精力、健康、资金等数值
- 学习、打工、创业、社交、休息、探索行动
- 随机事件与选择分支
- 四位可攻略角色、独立性格/台词/好感度
- 回合推进、年龄与月份变化、结局判定
- 本地存档与重新开局
- 手机响应式界面

## 当前原型的边界
- 这是手机网页原型，不是已发布的微信小游戏，也没有在线托管链接。
- 头像使用 emoji 占位；后续可替换为原创立绘、背景图、CG 和音效。
- 经济数值、事件概率和剧情量属于初版占位，需要试玩后平衡。
- 存档仅保存在同一浏览器/设备；清除浏览器数据会清掉存档。

## 后续迁移到微信小游戏
1. 安装微信开发者工具并新建“小游戏”项目。
2. 将玩法逻辑拆分为状态管理、事件引擎、角色数据和渲染层。
3. 使用小游戏 Canvas/API 重写界面，使用 `wx.setStorageSync` / `wx.getStorageSync` 保存进度。
4. 在真机调试触摸交互、屏幕适配、存档与资源加载。
5. 按微信平台要求配置、测试并提交审核。
