# 东京人生：心动与野心 — MVP 0.1

这是一个可运行的手机网页原型，用于验证微信小游戏的核心玩法。

## 运行方式
1. 解压 ZIP。
2. 在浏览器中打开 `index.html` 即可游玩。
3. 推荐用手机 Safari/Chrome 打开；当前存档保存在该浏览器的 localStorage 中。

## 当前实现
- 随机家庭背景、性格与能力起点；新开局统一为24岁、200000日元、精力100%、健康90
- 学识、技能、社交为无100点上限的累计点数；精力允许降至−10，健康仍在0–100内，角色好感度保留原有上限
- 初始设定仅作用于新人生；读取旧存档保留已有年龄、资金和属性
- 学识、技能、社交、精力、健康、资金等数值
- 学习、打工、创业、社交、休息、探索行动
- 随机事件与选择分支
- 四位可攻略角色、独立性格/台词/好感度
- 每天分上午／下午两个时段，下午结束推进到次日；夜间固定恢复20点精力
- 精力降到−10后强制养病7天（14个时段），跳过原计划，精力恢复100、健康减少10；跳过的学习不计完成
- 月末扣除生活费，跨年增长年龄；日历使用每年365天的游戏简化规则
- 行程规划：只保留周安排，左侧周一至周日每天左右两格（上午／下午），右侧学习／娱乐，默认显示学习
- 显示周次、日期、当前时段与本周日期范围；执行记录带日期和时段
- 移除五十音独立活动；初级日语在8个不同时段安排过后，解锁中级日语、JLPT与日语听力，进度随存档保留
- 同一时段重复安排不重复计数，获得的解锁不因调整行程而丢失；其他技能可独立学习
- 增加高级日语：实际完成中级日语8次后解锁；课程的安排次数与实际完成次数分别记录
- JLPT（游戏内规则）：4月报7月1日上午考试，9月报12月1日上午考试，每场只能报名一个等级，考后45天固定弹窗通知
- N5须实际完成初级日语8次；N4再需中级8次；N3再需高级8次；N2／N1另需对应备考8次；不满足或缺考即不合格
- 考试当天锁定合格条件快照，考后补学不改变当次成绩；合格证书永久保存在人生记录，成绩与未读通知随存档保存
- 考试与养病为系统固定时段；养病期间缺考，照常等待成绩日收到不合格通知
- 技能学习与多种休闲活动；选择时段后填入活动，自动存档
- 点击「执行上午／下午」应用活动效果并推进一个时段；未安排的时段默认休息，事件需先处理
- 旧版单日计划迁入对应日期上午，已移除的五十音安排转为初级日语；保留原有人物属性和进度
- 本地存档与重新开局
- 手机响应式界面
- 标题板内部底部一排七个方形图标：个人状态、人生进程、行程规划、命运中的人、人生记录、存档和读档
- 存档与读档为左右双面板：左侧8个档位，右侧预览／操作；前2个免费且可反复覆盖，后6个灰色锁定，每格花费5000游戏内日元解锁
- 手动存档支持覆盖、读档和删除；覆盖／读档／删除／解锁前确认，删除后档位仍保留，解锁状态由存档和读档共用
- 自动续玩进度单独保存，不占手动档位；旧单档首次迁入免费档位1，开始新人生不清除手动档
- 解锁状态保留在当前浏览器，读旧档时结算同一人生尚未计入的档位费用，避免回档免单或重复扣费
- 窗口右上角「收起」返回主画面，也支持 Esc 或点击窗口外关闭；内容较长时仅窗口内部滚动
- 新事件会在「人生进程」图标显示提示圆点，也可从行动或角色分区跳转处理

## 当前原型的边界
- 这是手机网页原型，不是已发布的微信小游戏，也没有在线托管链接。
- 头像使用 emoji 占位；后续可替换为原创立绘、背景图、CG 和音效。
- 经济数值、事件概率和剧情量属于初版占位，需要试玩后平衡。
- 存档仅保存在同一浏览器/设备；清除浏览器数据会清掉存档。

## 后续迁移到微信小游戏
1. 安装微信开发者工具并新建“小游戏”项目。
2. 将玩法逻辑拆分为状态管理、事件引擎、角色数据和渲染层。
3. 使用小游戏 Canvas/API 重写界面，使用 `wx.setStorageSync` / `wx.getStorageSync` 保存进度。
4. 在真机调试触摸交互、屏幕适配、存档与资源加载。
5. 按微信平台要求配置、测试并提交审核。

## 目录
- `index.html`：可运行的手机网页原型
- `planner.js` / `planner.css`：行程规划逻辑、活动清单与左右面板布局
- `life-systems.js`：日常恢复、强制养病、JLPT报名／考试／成绩与证书系统
- `save-manager.js` / `save-manager.css`：8档位存读档、解锁和标题板底部导航
- `README.md`：说明与后续开发路线
- `game-design.json`：游戏数据结构与设计草案

## 检查
- 运行 `python tests/browser_checks.py`，使用本机 Chrome 检查计划编辑、按天执行、事件、旧存档兼容和窄屏左右布局。
- 可用 `CHROME_PATH` 指定 Chrome 可执行文件路径。
